# Privacy policy

This application runs entirely offline. It does not connect to the internet and
does not collect, transmit, sell or share any personal data. It contains no
telemetry, analytics, advertising or tracking of any kind.

Files you open are read and processed locally, and only on your device. The
application stores two things on your computer: a small settings file holding
the last used folder and your chosen library path, and an index file in the
folder you select as your library. Both remain local, are readable only by
your user account, and can be deleted at any time; clearing the index inside
the application removes the index file.

Uninstalling the application does not remove those files automatically.
Delete them manually if you want no trace.

This policy applies to all versions distributed from this repository.
